# 파일 기반 텍스트 교환

클립보드 복사/붙여넣기가 안 될 때, `.claude/exchange.md` 파일 하나를 사용자와 나 사이의 간이 통로로 씁니다.

## 파일 구조

`.claude/exchange.md`는 항상 아래 두 섹션만 가집니다 — 각 섹션은 **매번 덮어쓰기**하고 누적하지 않습니다(오래된 내용과 헷갈리지 않도록).

```markdown
## FROM_USER
(사용자가 나에게 전달할 내용을 여기에 붙여넣음)

## FROM_CLAUDE
(내가 사용자에게 전달할 내용을 여기에 작성함)
```

## 사용 흐름

**사용자 → 나 (사용자가 뭔가 전달하고 싶을 때)**
1. 사용자가 `## FROM_USER` 섹션에 텍스트를 붙여넣고 저장한 뒤 "파일 확인해줘"라고 말함
2. 나는 `Read`로 `.claude/exchange.md`를 읽어서 `## FROM_USER` 섹션 내용을 확인
3. 확인 후에는 `## FROM_USER` 섹션을 비워서(다음 번에 헷갈리지 않게) 정리해도 되는지 물어보거나, 사용자가 명시적으로 요청하면 비움 — 임의로 먼저 지우지 않음(사용자가 다시 참고할 수도 있으므로)

**나 → 사용자 (사용자가 특정 내용을 파일로 달라고 할 때)**
1. 사용자가 "이거 파일에 써줘" / "OO 내용 파일로 줘" 라고 요청
2. 나는 `## FROM_CLAUDE` 섹션에 요청받은 내용을 작성(기존 내용은 덮어씀)
3. 사용자에게 "`.claude/exchange.md`의 FROM_CLAUDE 섹션에 작성했다"고 알림 — 파일 내용을 채팅에 다시 출력하지 않음(애초에 복붙이 안 돼서 파일을 쓰는 것이므로 중복 출력은 의미 없음, 단 사용자가 명시적으로 채팅에도 보여달라고 하면 예외)

## 주의

- 이 파일은 저장소에 커밋되면 안 됩니다 — `.gitignore`에 이미 등록되어 있는지 확인하세요(`.claude/exchange.md`). 임의 텍스트(민감 정보 포함 가능)가 오갈 수 있는 개인용 스크래치 파일입니다.
- 파일이 없으면 먼저 만들고(빈 `FROM_USER`/`FROM_CLAUDE` 섹션으로) 시작하세요.
