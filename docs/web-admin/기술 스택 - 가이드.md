# 기술 스택 - 가이드

## 개요

Picake 관리자 웹 애플리케이션(web-admin)의 실제 구현된 기술 스택을 정리한 가이드입니다. web-seller와 동일한 React + Vite 기반이지만, 외부 노출 서비스가 아닌 내부 도구인 만큼 Sentry/PostHog/Socket.IO 등은 사용하지 않습니다.

## 핵심 기술 스택

### 1. Vite

- 개발 서버 포트 3003, `@vitejs/plugin-react`로 JSX/TSX 지원
- 경로 별칭(`@/apps/web-admin`)으로 절대 경로 사용
- `import.meta.env.VITE_PUBLIC_GITHUB_SHA`로 빌드 정보(`BuildInfoLogger`) 노출

### 2. React (v18) + React Router (v7)

- `BrowserRouter` + `Routes`/`Route` 기반 SPA 라우팅
- `common/constants/paths.constant.ts`의 `ROUTES`/`AUTH_ROUTE_CONFIG`/`ADMIN_ROUTE_CONFIG`로 라우트 중앙 관리
- 인증 필요 라우트는 `AuthInitializerProvider` + `AdminLayout`으로 감싸 처리

### 3. Tailwind CSS + 자체 UI 컴포넌트

- Tailwind CSS(v3) + `class-variance-authority`(CVA) 기반 variant 스타일링, `tailwind-merge`/`clsx`로 클래스 병합
- `common/components/` 하위 기능별 폴더(`buttons`, `inputs`, `selects`, `labels`, `cards`, `alerts`, `badges`, `fallbacks`, `layouts`)에 `Base*.tsx`(CVA 정의) + 상위 래퍼 컴포넌트 패턴으로 구성 (web-seller와 동일한 패턴)
- `@radix-ui/react-label`, `@radix-ui/react-select`, `@radix-ui/react-slot` 등 Radix 프리미티브 사용
- `lucide-react` 아이콘, `qrcode.react`로 TOTP 설정 시 QR 코드 렌더링

### 4. TanStack Query (v5)

- `QueryProvider`로 전역 설정, 서버 상태 캐싱·리페칭
- `@tanstack/react-query-devtools`로 개발 환경 쿼리 모니터링

### 5. Zustand (v5)

- 인증 상태(TOTP 검증 여부 포함) 및 전역 알림 상태 관리

### 6. Axios

- API 클라이언트(baseURL, timeout), Authorization 헤더에 Bearer 토큰 포함(localStorage)
- 401 응답 시 로그인 페이지 리다이렉트

### 7. react-error-boundary

- `ErrorBoundaryProvider`로 전역 에러 처리, `ErrorFallback` 표시

### 8. recharts

- 통계 대시보드(회원/주문/스토어/입점요청)의 차트 렌더링
